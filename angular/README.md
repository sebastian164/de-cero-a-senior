## Relación con la ruta Java

Los conceptos de diseño (orientación a objetos, SOLID, patrones, arquitectura, liderazgo) no dependen del lenguaje. La explicación larga de cada uno, con analogías, casos y excepciones, está en la [ruta Java](../java/). Esta ruta enlaza a esas lecciones y se concentra en cómo se aplican con TypeScript y Angular. Puedes seguirla sin saber Java: los ejemplos de aquí son autosuficientes.

## Versión de Angular

Angular publica versiones mayores con frecuencia y ha cambiado varias recomendaciones en los últimos años. Esta ruta usa el estilo moderno: componentes independientes, señales, control de flujo integrado (`@if`, `@for`), `inject()`, `input()` y `output()`, y detección de cambios sin zona. Las API más recientes (formularios con señales, `resource`) se mencionan indicando que debes confirmar su estado. Ante cualquier diferencia, manda la documentación oficial de tu versión: angular.dev.

## Sobre el código

Todo el código de esta ruta es ilustrativo: no se compiló ni se ejecutó al preparar el curso. Hacerlo funcionar en un proyecto real es parte de cada taller.

## Requisitos

- Node.js en una versión LTS vigente y la CLI de Angular.
- Conocer HTML y CSS básicos.
