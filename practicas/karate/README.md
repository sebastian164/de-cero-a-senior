# Karate: pruebas de API

Tres talleres, en orden. Requisito: JDK 21 y la API de [Bitácora](../../docker-kubernetes/app/) corriendo (`java Servidor.java`).

| # | Sesión | Taller |
|---|---|---|
| 01 | [Primera prueba de API con Karate](01-primera-prueba-de-api/) | Cubrir todas las rutas de Bitácora, con casos de error |
| 02 | [Aserciones, datos y reutilización](02-aserciones-datos-y-reutilizacion/) | Una suite guiada por datos que corre en dos ambientes |
| 03 | [Mocks, ejecución en paralelo e integración continua](03-mocks-paralelo-y-ci/) | Simulador, paralelo y flujo automático |

Los archivos de Karate de estas sesiones son ilustrativos: no se ejecutaron al preparar el curso. Están escritos para la serie 2; si algo no coincide con tu versión, manda la [documentación oficial](https://docs.karatelabs.io).
