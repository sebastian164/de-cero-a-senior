# Solución de referencia: taller TDD 03, el parqueadero heredado

> Intenta el taller antes de leer esto: ver la respuesta primero convierte el taller en lectura.

Proyecto Maven autónomo (JDK 21 y Maven). Esta carpeta guarda el estado final del código; tu propia entrega va en `taller/solucion/`.

## Ejecutarla y probarla

```bash
mvn test
```

Corre las pruebas de reglas, de vehículos eléctricos, de salida y la prueba de caracterización con su muestra (`src/test/resources/muestra.txt`). `Parqueadero.java` queda en `src/main/java/`, ya refactorizado.

Las decisiones, la lista de pruebas y las respuestas a los pasos del taller están en [ANALISIS.md](ANALISIS.md).
