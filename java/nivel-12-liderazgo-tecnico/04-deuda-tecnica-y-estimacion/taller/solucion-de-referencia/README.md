# Solución de referencia: taller 12-04 (deuda técnica y estimación)

> **Intenta el taller antes de leer esto:** ver la respuesta primero convierte el taller en lectura. Esta carpeta es una solución de referencia para comparar con la tuya, no un punto de partida. Tu entrega va en `taller/solucion/`.

## Qué instalar

Solo Python 3.

## Cómo ejecutarla y probarla

Desde esta carpeta:

```bash
python3 calcular.py
```

Calcula la estimación de tres valores (PERT) de la funcionalidad del taller, con su desviación y sus niveles de confianza, y el sesgo de tres estimaciones pasadas (un caso ficticio). Termina con código 0 si sus comprobaciones (`assert`) pasan. No levanta nada ni deja archivos.

Los datos de estimaciones pasadas son ficticios: en tu entrega usa los tuyos. Las decisiones y las respuestas a cada paso están en [`ANALISIS.md`](ANALISIS.md).
