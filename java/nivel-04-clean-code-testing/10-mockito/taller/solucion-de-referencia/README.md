## Cómo ejecutarla

Requiere JDK 21. Desde esta carpeta:

```bash
./ejecutar-pasos.sh
```

Requiere además Maven 3.9 o superior y git. Cada paso de `pasos/` tiene su código completo, el mensaje de commit y el resultado esperado de `mvn test`; el paso 03 es un intento que no compila a propósito y no entra al historial. El script también comprueba que el `Main` de cada paso imprime lo mismo que `../../../../nivel-02-solid/05-dip/taller/inicio/`.

El razonamiento, punto por punto, está en [ANALISIS.md](ANALISIS.md).
