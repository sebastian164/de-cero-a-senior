# Nivel 2 — Principios SOLID

Cinco criterios para repartir responsabilidades y dependencias de modo que cambiar el código sea barato. Son heurísticas, no leyes: cada lección incluye cuándo no aplicarlas.

| # | Lección |
|---|---|
| 01 | [S — Responsabilidad única (SRP)](01-srp/) |
| 02 | [O — Abierto/cerrado (OCP)](02-ocp/) |
| 03 | [L — Sustitución de Liskov (LSP)](03-lsp/) |
| 04 | [I — Segregación de interfaces (ISP)](04-isp/) |
| 05 | [D — Inversión de dependencias (DIP)](05-dip/) |
| 06 | [Taller integrador](06-taller-integrador/) |

Desde la lección 02, cada ejemplo es un único archivo: `java Main.java`.

En la lección 01 cada ejemplo tiene varios archivos; se compila y ejecuta desde su carpeta con `javac *.java` y `java Main`.
